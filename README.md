# Bruna Sena — Landing Page

Protótipo reconstruído em React + Vite a partir da imagem fornecida.

## Rodar
```bash
npm install
npm run dev
```

## Observação
As imagens usadas em `src/assets` são recortes temporários da própria imagem de referência. Para a versão final, substitua por fotos originais em alta resolução da Bruna e dos alunos.

Também substitua o número/links de WhatsApp e Instagram no `src/main.jsx`.
